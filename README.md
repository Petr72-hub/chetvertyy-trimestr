# Четвёртый триместр

Мобильный прототип пространства для мам. Работает как обычный статический сайт: без сборки, аккаунта и API-ключей.

## Открыть на компьютере

Откройте `index.html` в браузере. Для проверки через локальный сервер нужен Node.js 18 или новее:

```powershell
npm start
```

Затем откройте `http://127.0.0.1:4173`.

## Разместить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите **содержимое этой папки** в корень репозитория. Файл `index.html` должен находиться в корне.
2. В репозитории откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, затем свою основную ветку и папку **/(root)**, сохраните.
4. Дождитесь ссылки на опубликованный сайт в том же разделе.

GitHub Pages открывает сайт всем, у кого есть ссылка. Не размещайте в репозитории реальные персональные или медицинские данные.

## Что есть в прототипе

- Главная с приветствием, цитатой, четырьмя направлениями и карточкой материала.
- Профиль и подборка материалов по этапам развития малыша.
- Статьи для мамы и ребёнка, поиск и сохранение.
- Демонстрационные чаты и знакомства с вымышленными профилями.
- Локальный бот: ответы по темам сна, ухода, кормления и поддержки, уточнение возраста, ссылки на материалы и источники.
- Небольшая заставка с птицей, которую можно пропустить; при настройке уменьшенной анимации она выключена.

Фото `assets/quiet-morning.jpg` сгенерировано специально для этого прототипа. Других фотографий на главной нет. Логотип сохранён из исходной версии проекта.

## Границы работы

Это демонстрационный сайт. Общения между реальными пользователями, регистрации, нейросети и дежурного психолога пока нет. Бот работает по правилам и не ставит диагнозы. Экстренные подсказки в чате не заменяют медицинскую помощь. Профиль и сохранённые материалы хранятся в браузере; демонстрационная переписка исчезает после перезагрузки вкладки.

## Проверка

```powershell
npm run check
npm test
```

Также проверены основные экраны на ширине 320 и 390 пикселей, загрузка фотографии и отсутствие горизонтальной прокрутки и ошибок в консоли браузера.
